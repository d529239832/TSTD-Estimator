# IEEE80211g

下载parquet 文件，将其存储在“mixture models/wifi/measurement _ loc _ results”和“mixture models/wifi/measurement _ length _ results”中。

我们主要关注`wifi/measurement_length`数据。

# 数据集预处理
```
python -m mixturemodels prep_dataset -d wifi/measurement_length --preview
python -m mixturemodels prep_dataset -d wifi/measurement_length -x '{"length":[172,3440,6880,10320]}' -l wifi/prepped_length -n length

```

# 计算阈值
```
python -m mixturemodels phase_one -d wifi/prepped_length -t receive -x 0,1,2,3 -l wifi/validate_length_l --plot-tail --log -r 2 -c 2 -y 0,400,200
```

# 训练
所有长度合起来400w抽样一部分来训练出综合预测器
```
#原始论文实验 M+EVM
python -m mixturemodels train -d wifi/prepped_length -l wifi/trained_length_dl_l -c mixturemodels/wifi/train_conf_dl_o.json -e 9 -t WIFI
# EVM
python -m mixturemodels train -d wifi/prepped_length -l wifi/trained_length_dl_l -c mixturemodels/wifi/train_conf_dl_v.json -e 9 -t WIFI
#W2WU
python -m mixturemodels train -d wifi/prepped_length -l wifi/trained_length_dl_l -c mixturemodels/wifi/train_conf_dl_w.json -e 9 -t WIFI
#手动 输入阈值方式 测试
python -m mixturemodels train -d wifi/prepped_length -l wifi/trained_length_dl_l -c mixturemodels/wifi/train_conf_dl_w.json -e 9 -t WIFI -u 0.5,1,2,3 -v 10,11,12,13
```
